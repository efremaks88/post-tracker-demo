# Локальная версия ПОСТ ТРЕКЕРА

## Обычный запуск на Windows

1. Дважды нажмите `START_LOCAL.bat`.
2. При первом запуске установка npm-компонентов может занять несколько минут.
3. Браузер откроет Трекер автоматически, обычно по адресу `http://127.0.0.1:3080`.
4. Оставьте окно запуска открытым. Чтобы остановить Трекер, нажмите в нём `Ctrl+C` или закройте окно.

Если локальный Трекер уже запущен, повторный запуск `START_LOCAL.bat` просто откроет его в браузере. Если порт `3080` занят другой программой, запуск сам выберет следующий свободный локальный порт.

Если система сообщает, что Node.js не найден, один раз запустите `INSTALL_LOCAL.bat`, а затем снова `START_LOCAL.bat`. Поддерживается Node.js 20 и новее.

## Изоляция и хранение данных

Локальный режим принудительно слушает только адрес `127.0.0.1`: открыть его с другого компьютера нельзя. LDAP, корпоративная сеть и production PostgreSQL в этом режиме не используются. Сессия локального администратора создаётся автоматически и действует только в этом режиме.

Демонстрационная база создаётся в `local-data/pglite`. В ней есть три проекта, сотрудники, серии, этапы и задачи около текущей даты. Изменения сохраняются между запусками. Каталог `local-data` исключён из Git и не попадает в коммиты.

В верхней части интерфейса локальная сборка помечена `DEV · v0.2.3`.

## Перенос на другой Windows-компьютер

Скопируйте всю папку репозитория. Если нужно перенести сделанные локальные изменения, копируйте и каталог `local-data`. На новом компьютере запустите `START_LOCAL.bat`; при отсутствии Node.js сначала запустите `INSTALL_LOCAL.bat`.

Локальный режим предназначен для демонстрации и индивидуального тестирования. Он использует одну встроенную базу и не рассчитан на одновременную работу нескольких компьютеров.
