# D2.8 — понятные задачи и создание проекта

Локальная сборка `DEV · v0.13.0` убирает двусмысленные галочки из списка задач на главной. Вместо них используется цветовая метка проекта: задача остаётся невыполненной, пока пользователь не отметит её внутри блока.

На главной и в каталоге проектов появилась кнопка **«Создать проект»**. Форма сохраняет название, описание, стадию и цвет в локальную базу, назначает создателя менеджером проекта и открывает пустую карту для дальнейшего наполнения блоками. Серверная операция и событие общей истории записываются в одной транзакции.

Автоматическая проверка покрывает сохранение проекта, назначение создателя, доступ к новой карте, событие аудита и отклонение некорректной формы без частичной записи.
