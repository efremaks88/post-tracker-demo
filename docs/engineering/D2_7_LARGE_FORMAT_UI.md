# D2.7 — крупный формат интерфейса

Локальная сборка `DEV · v0.12.0` увеличивает основной масштаб продюсерской без изменения её рабочих сценариев.

- Навигация, заголовки, задачи, сроки и предупреждения стали заметно крупнее.
- Карточки проектов сохраняют чистую фотографию в верхней части и используют градиент только под текстом.
- Календарь получил крупные даты, события и подробную панель выбранного дня.
- Команда показана крупными сводными карточками. Текущая работа раскрывается по запросу, двойной щелчок по-прежнему открывает полную карточку сотрудника.
- На узких экранах разделы сохраняют адаптивную раскладку и горизонтальный календарь.

Изменение не затрагивает production, права пользователей, расчёт загрузки и формулы аналитики.
