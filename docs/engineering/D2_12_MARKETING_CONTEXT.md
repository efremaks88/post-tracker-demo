# D2.12 — сквозной контекст постпродакшна и маркетинга

Версия `DEV · v0.17.0` связывает продюсерскую с уже существующими датами пост-трекера.

## Что добавлено

- верхняя вкладка «Маркетинг» с общей картиной по проектам и выпускам;
- вехи монтажа, предмастера, ОТК, мастера и эфира из общей модели серии;
- объяснимые состояния маркетинговой готовности: рано, пора готовить запуск, материал готов, риск и нет даты;
- короткая монтажная сводка внутри карты проекта;
- упрощённое создание проекта, блока и задачи;
- перенос задачи между группами перетаскиванием;
- полная верхняя навигация без скрытых разделов;
- прямой переход из контекста поста в отфильтрованный гант этого проекта;
- обновлённая тёплая визуальная система без избыточной декоративной бумаги.

## Источник данных

Маркетинг и продюсерская не хранят копии дат. API читает поля серии `edit_start`, `pre_otk_date`, `otk_date`, `send_date` и `air_date`, а также запланированные пост-смены из `tasks`. Поэтому изменение ключевой даты в пост-трекере отражается в обоих новых представлениях.

## Демо-данные

GitHub Pages получает согласованные данные из `pages-fixtures/marketing.json`. Скрипт `scripts/sync-production-context-fixtures.js` синхронизирует серии, монтажные смены и карточки проектов.

Локальные пользовательские изменения не перезаписываются автоматически. `RESET_PRODUCER_DEMO.bat` обновляет только демонстрационные проекты и теперь также приводит их ключевые пост-даты к текущему периоду.
